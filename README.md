A 4 KB chess engine in Python. 0x88 board, alpha-beta with null-move pruning, quiescence over captures, transposition table, Michniewski piece-square tables. Deterministic fixed node budget (40,000 search nodes). Talks to the env over HTTP.

Built for [make.fun](https://make.fun/r/thr15azb) bounty tiny-chess-01.
